# proyectoFinalMetodosNumericos
proyecto final de la clase de metodos numericos 5to ciclo
INSTRUCCIONES DE DESPLIEGUE--
1.Clonar el repositorio: git clone https://github.com/JL-RZ21/proyectoFinalMetodosNumericos.git--
2.Copiar el archivo de entorno: cp .env.example .env--
3.Editar .env con los valores reales de contraseña y configuración.--
4.Ejecutar: docker compose up --build --
5.Acceder al frontend en: http://localhost:5173--
6.Acceder a Swagger en: http://localhost:5000/swagger--
