# proyectoFinalMetodosNumericos
proyecto final de la clase de metodos numericos 5to ciclo
INSTRUCCIONES DE DESPLIEGUE
Clonar el repositorio: git clone https://github.com/JL-RZ21/proyectoFinalMetodosNumericos.git
Copiar el archivo de entorno: cp .env.example .env
Editar .env con los valores reales de contraseña y configuración.
Ejecutar: docker compose up --build
Acceder al frontend en: http://localhost:5173
Acceder a Swagger en: http://localhost:5000/swagger
